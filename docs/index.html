FAQ

Questions we kept hearing.

Is there really no LLM in the loop? +
Correct. Recording is a deterministic capture of DOM events and network state. Replay is a deterministic re-execution of the same events. No language model interprets anything, ever — so behavior is identical across runs.
What happens when a site changes? +
pnv pins to stable anchors (data-* attributes, ARIA roles, structural paths) and falls back through a ranked list. When a step can't be located, the task halts with a diff against the original transcript so you can fix it in one click rather than debug it.
How is this different from other browser automation tools? +
Most existing tools split into two camps: code-based runtimes for engineers, or agent-based runtimes driven by LLMs. pnv is neither — you decide what should happen by doing it once, and the runtime just replays. Different problem, different tool.
Can I call a task from code? +
Yes. Every task has a stable HTTPS endpoint. POST JSON with your variables, get back a run id and a transcript URL. SDKs for JS, Python, and Go are on the way.
Where does the cloud browser run? +
Frankfurt, Virginia, and Singapore today. Self-host is available on Team plans for everywhere else.
