## FAQ

**Section label:** `Section 07 · FAQ`

**H2:** `Questions we kept hearing.`

### Q1: Will my account get flagged or banned?

pnv runs a real Chromium browser — not a script, not an API call. From the platform's perspective, it looks like a person using a browser, because it is. That said, aggressive automation on any platform carries risk. We recommend keeping task frequency within what a human would reasonably do. pnv is a personal automation tool — you decide the pace.

### Q2: Which platforms does pnv support?

Any platform your browser can reach: X (Twitter), Threads, Instagram, TikTok, LinkedIn, YouTube, and more. pnv doesn't use platform APIs — it uses the browser UI directly, so there are no API keys to manage and no rate limits from the platform side.

### Q3: How is this different from Buffer or Hootsuite?

Buffer and Hootsuite schedule posts. That's it. pnv automates any browser action — like, comment, follow, scrape analytics, DM, fill forms, extract data. If you can do it in a browser, pnv can do it on a schedule.

### Q4: How is this different from Phantombuster?

Phantombuster requires you to configure automation scripts and workflows. pnv records what you do and replays it. No setup, no templates, no maintenance when the platform UI changes — just redo the recording.

### Q5: Can I manage multiple social media accounts?

Yes. Each browser profile has its own cookies, session, and login state. Create a profile per account. Run separate tasks per profile. Profiles are free and unlimited.
